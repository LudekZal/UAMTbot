2026/10/09 - new 3D files for basic FEKTbot robot, as well as higher level plate
- FEKTBOT_base_ver_1_2           - base, prepared for stacking up higher levels
- FEKTBOT_wheel_shaft_ver_1_2    - wheel, no insert needed
- FEKTBOT_upper_ver_1_2          - upper level plate - unspecified usage, prepared for main ON/OFF switch, several holes for cables and mounting
- FEKTBOT_RPI_3or4_ver_1_2       - upper level plate prepared for Raspberry pi 3 or 4, preparation for higher level (e.g. lidar, camera, ...)
- FEKTBOT_RPlidar_ver_1_2        - 3rd level plate, non-specific usage (lidar, ...)

Each model is provided with 3 files - 3D Fusion360 model (09/2026 version), 3mf (modern 3D printers), STL (binary, for older 3D printers)
